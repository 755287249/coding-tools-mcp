# 浏览器种子插件 v1.3.1

1. 更新客户端至 0.1.135，打开项目的“种子库”。填写公开 MCP 地址，生成配对令牌并保存。客户端会补齐当前项目的配对地址。
2. 安装 Tampermonkey，再安装同一版本 Release 的 `coderabbit-seeds.user.js`。
3. 在 CodeRabbit 的 **New coding task** 页面选择组织、仓库和分支。打开右下角“种子库”，粘贴客户端的配对地址与令牌，点击“连接并保存”。
4. 检查脚本自动显示的账号、GitHub ID、仓库 ID、组织、工作区和分支；填写模型前缀（例如 `GPT-6-astra`）和创建数量，确认后逐个创建。建议第一次用 2–3 颗验证。
5. 客户端显示实时状态，支持搜索、账号/状态筛选、分页和悬停详情。开启“新对话自动分配种子”后，新建工作对话即可分配待命种子。

## 保存与容量

- 客户端按项目保存配对地址/令牌；油猴保存连接和上次数量。客户端注册表仅保存配对令牌哈希。
- 网页登录令牌和入库票据只在内存中使用，不额外写入浏览器存储。创建结果单独保存，面板显示最近 200 条。
- 客户端最多保留 **10000 条记录**（包括归档历史），每页显示 50 条。脚本可输入 1–10000，每次领取最多 10 张票据，再逐个提交任务。
- 配对令牌只允许查询容量和给当前项目添加种子，不能调用项目工具。保存新令牌或撤销会使旧令牌失效，已接入种子的独立凭据不受影响。
- 配对地址需要浏览器可访问的 HTTPS；同一台机器也可使用 HTTP 回环地址。

## 停止、恢复与边界

- 切换账号、组织、工作区、仓库、分支或退出登录后，脚本停止剩余创建。页面重新选择完成后可点击“刷新账号和仓库”。
- 配对请求超时可用同一编号继续，不重复领取同一批。任务创建结果不明时停止并阻止重复提交，请先到 CodeRabbit 任务列表核对完整种子 ID。
- 保持当前页面可继续本轮；更换连接前先结束本轮。刷新/关闭页面会丢失未提交票据；已创建任务继续由宿主管理。
- 已创建任务的登记失败时，继续本轮会先重试登记，不会重建任务。
- 一个项目目录一旦已有种子接入或登记宿主任务，就绑定精确仓库和分支；不同仓库/分支使用另一个项目目录。
- 客户端等待十分钟无活动，再留两分钟宽限。有操作未完成或等待用户确认时不会自动接替。主动断开关闭当前对话自动分配。
- 接替保留本地对话 ID、消息、计划。宿主沙箱文件、服务和模型记忆不迁移；成果通过 MCP 工作区保存。
- 入库票据一小时过期，初始化响应在同一服务进程中可重试一分钟，种子访问令牌有效七天。
- 数量上限不是在线并发承诺。账号额度、并发和执行时限由 CodeRabbit 决定。脚本使用当前已登录账号，不代为注册、激活资格或处理账单。
- 页面内部接口可能变化；无法唯一确认仓库或返回真实任务 ID 时会停止。

发布时将 `static/plugins/coderabbit-seeds.user.js` 以 `coderabbit-seeds.user.js`
名称上传到对应客户端 Release。

## 模型分类与自动接入

- 油猴创建的种子来源为 `coderabbit`，模型前缀会保存到客户端和宿主任务标题。
- 客户端可按来源、账号、前缀关键词筛选；展开单颗种子可以修改来源和前缀。
- 开启自动分配后，新建对话会真正创建并开始等待：只有一种分类时直接载入，多分类时先选卡片或输入来源/关键词。不再需要点“接入 AI”。
- 对话保存选择的来源与关键词；首次分配和失活接替都匹配同一条件，缺少匹配种子时等待，不跨模型回退。
- 加入 Arena 等其他宿主：在种子库打开“手动加入单个 AI”，填写来源、前缀、账号和 MCP 地址，将生成的提示词交给一个 AI。无需 CodeRabbit 仓库 ID。
- “直接为此对话接入 AI”保留原有单对话手动连接方式。

## 1.3.1 交互修复

- 面板适配网页弹窗的焦点和鼠标限制，输入、粘贴和按钮可正常使用；页面切换保留当前面板节点。
- 连接期间立即显示状态并禁止重复提交，失败后可重试。网络失败提示检查地址与油猴访问权限。
- 客户端连接区域由用户控制展开，刷新库存和保存不会自动收起。两端令牌均可点击显示／隐藏。
