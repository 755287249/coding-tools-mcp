# 浏览器种子插件 v1

1. 更新并启动带种子库功能的 Coding Tools MCP。选择项目，打开左侧“种子库”。
2. 安装 Tampermonkey，再安装同一版本 Release 中的 `coderabbit-seeds.user.js`。
3. 在客户端输入账号/池名称、精确 CodeRabbit 仓库 ID、分支和可公开访问的 MCP 地址，生成 1–50 颗批次。建议首次用 2–3 颗确认账号能力。
4. 打开已登录的 `https://app.coderabbit.ai`，点击右下角“种子库”，粘贴批次，填写当前组织 ID（以及需要时的 Workspace ID）。确认账号、仓库和数量后开始。
5. 脚本逐个创建任务；“已创建”不代表 AI 已接入。客户端收到初始化与等待请求后才显示“可分配”。开启“新对话自动分配种子”，新建工作对话即可排队接入。

## 恢复与边界

- 客户端默认等待十分钟无活动，再留两分钟宽限；有命令在运行或等待用户确认时不自动替换。
- 原有对话 ID、消息、计划保留。旧种子凭据会被撤销，新种子读取已有状态继续。宿主自己的沙箱文件、服务和内部模型记忆不会迁移；项目成果通过 MCP 工作区保存。
- 断开 AI 会关闭该对话的自动分配，尊重主动暂停。归档失活种子保留退役记录与累计数量。
- 批次票据一小时过期；初始化响应可在同一服务进程中重试一分钟。访问令牌只保存在宿主客户端内存，有效七天。失去令牌或宿主无法唤醒时使用新种子接替。
- 浏览器只保存不含凭据的创建结果。已提交或状态不明的种子不会自动重建。网络中断后，到宿主任务列表搜索完整种子 UUID 核对；不要反复点击创建同一批次。
- 脚本使用当前浏览器登录会话，不代为注册账号、激活资格或处理账单。页面内部 tRPC 接口可能变化；明确检查错误与真实任务 ID，失败就停止批次。
- 50 是每批上限，不是宿主并发保证。账号额度、并发与执行时限仍由宿主决定。关闭浏览器会停止剩余创建，已创建任务的执行由宿主管理。

## 开发

修改 `core.mjs` 或 `browser.js` 后运行：

```sh
node plugins/coderabbit-seeds/build.mjs
node plugins/coderabbit-seeds/build.mjs --check
node --test tests/seed-plugin.test.mjs
```

生成文件在 `static/plugins/coderabbit-seeds.user.js`。发布客户端后，将该文件以
`coderabbit-seeds.user.js` 名称上传到同一版本 Release，客户端安装链接指向该资源。
